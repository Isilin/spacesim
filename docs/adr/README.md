# Architecture Decision Records

Convention de nommage : `NNNN-titre-en-kebab-case.md`, numérotation séquentielle à 4 chiffres,
jamais réutilisée même si une ADR est dépréciée.

Gabarit : [template.md](template.md).

Une ADR capture le *pourquoi* d'une décision structurante et les alternatives écartées — pas
le *quoi* (ça, c'est [docs/architecture.md](../architecture.md)) ni la feuille de route (ça,
c'est [docs/design.md](../design.md)).

Une ADR n'est pas modifiée après coup pour refléter un changement d'avis : une nouvelle ADR la
remplace et la référence (`Remplacé par [NNNN](NNNN-xxx.md)` dans son statut).
